# FitTap
FitTap — это разработанный веб-сервис автоматической проверки доступности сайтов по стандарту WCAG 2.1. Помогает выявлять барьеры для людей с нарушениями моторики и зрения. Стек: Python, Flask, Selenium, ReportLab

Анализирует:  
- размер кликабельных элементов (должен быть ≥44×44 px)  
- контрастность текста (обычный ≥4.5:1, крупный ≥3:1)  
- Walkthrough Score (доступность для клавиатуры)  

Результат отображается в виде подробного отчёта, который можно сохранить в PDF.

📁 Файлы проекта
`app_final.py` - Основной код веб-приложения (Flask + Selenium), содержит весь бэкенд и фронтенд (HTML/CSS встроены)
`requirements.txt` - Список зависимостей 
`Roboto-Regular.ttf` - Шрифт для корректного отображения кириллицы в PDF 
`templates` (папка) - HTML-шаблоны (в проекте они встроены в `app_final.py`) 

Инструкция по запуску 
1. Убедитесь, что установлен Python версии 3.8 или новее.
Проверить: python --version

2. Скачайте все файлы проекта в одну папку.
Основной файл: app_final.py.
При необходимости добавьте requirements.txt и шрифт Roboto-Regular.ttf.

3. Установите зависимости (библиотеки).
Если есть requirements.txt:
pip install -r requirements.txt
Если нет — установите вручную:
pip install flask selenium webdriver-manager reportlab

4. Запустите сервер:
python app_final.py

5. Откройте браузер и перейдите по адресу:
http://localhost:5000

6. Введите URL любого сайта (например, https://yandex.ru) и нажмите «Аудит».
Через несколько секунд появится подробный отчёт о проблемах с размером кнопок, контрастностью и клавиатурной навигацией. Отчёт можно сохранить в PDF!  :)

Актуальность проекта FitTap

С каждым годом доля людей с ограниченными возможностями здоровья (ОВЗ) в мире растёт. По данным Всемирной организации здравоохранения, более 1 миллиарда человек (около 15% населения Земли) имеют какую-либо форму инвалидности. Среди них – люди с нарушениями зрения (слепые, слабовидящие, дальтоники), с нарушениями опорно-двигательного аппарата (тремор, слабый контроль движений, паралич), а также пожилые люди, у которых с возрастом ухудшаются зрение и точность движений. Для всех них веб-сайты и приложения часто становятся непреодолимым барьером

Проблема: большинство сайтов не соответствуют стандартам доступности

Несмотря на существование международного стандарта WCAG 2.1 (Web Content Accessibility Guidelines), который четко определяет требования к размеру кликабельных элементов, контрастности текста, навигации с клавиатуры и другим параметрам, подавляющее большинство сайтов не проходят даже базовую проверку. Исследования показывают:

1. Более 90% сайтов государственных услуг имеют хотя бы одно критическое нарушение доступности

2. Кнопки и ссылки высотой менее 44 пикселей встречаются на 80% коммерческих сайтов, что делает их практически непригодными для людей с тремором

3. Контрастность текста ниже нормы (4.5:1) наблюдается на каждом втором сайте, что исключает возможность чтения для слабовидящих

Законодательное требование, а не просто рекомендация

Во многих странах, в том числе в России, с 2024-2025 годов вступили в силу поправки, обязывающие:

1. Государственные сайты и порталы образовательных учреждений соответствовать уровню доступности AA (WCAG 2.1)

2. Банки, страховые компании, операторы связи обеспечивать возможность использования сервисов людьми с инвалидностью

3. Школьные и вузовские сайты предоставлять альтернативные версии для слабовидящих

Однако отсутствуют простые, быстрые и понятные инструменты для самостоятельной проверки сайта разработчиками, дизайнерами и владельцами бизнеса. Существующие решений (Lighthouse, WAVE, Axe) сложны для неспециалистов, не дают визуально наглядного отчёта и не адаптированы для российских условий (например, часто не учитывают кириллицу в PDF-отчётах)

Социальная значимость и потенциал проекта FitTap

FitTap закрывает этот пробел. Он предоставляет:

1. Автоматический анализ двух ключевых критериев WCAG: размер цели (≥44×44 px) и контрастность текста (≥4.5:1)

2. ARIA-навигацию (Walkthrough Score) – оценку того, может ли пользователь с клавиатурой (без мыши) пройти по всем интерактивным элементам

3. Понятный визуальный отчёт с детальным списком проблемных элементов и рекомендациями по исправлению (с примерами CSS)

4. Генерацию PDF-отчёта с полными результатами, который можно приложить к заявке на устранение нарушений или использовать как доказательство для госорганов
