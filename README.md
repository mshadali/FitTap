# FitTap
FitTap — это разработанный веб-сервис автоматической проверки доступности сайтов по стандарту WCAG 2.1. Анализирует размер кликабельных элементов (≥44×44px) и контрастность текста (≥4.5:1). При аудите генерирует PDF-отчёт. Помогает выявлять барьеры для людей с нарушениями моторики и зрения. Стек: Python, Flask, Selenium, ReportLab
